# handoff v2.0 の変更点

v1 からの差分と、v1 から上げるときの注意。

## 変更点

- 停止前の「最後のメッセージに状況を書く」から Issue の ID を外し、書くのは作業の成果とユーザーに求めることだけにした。beads v2.0 の「beads は裏方の記録であり、ユーザーへの報告に書かない」と揃えるため。状況の詳細を Issue の note に残し、次のセッションがそこから再開する点は変わらない。
- 再開時に note と実際の状態が食い違っていたときの報告は、何が食い違っていたかを伝える形に言い換えた。
- 依存を `beads@v2.0` 以降に上げた。

## v1 から上げるときの注意

- 先に beads を v2.0 以降に上げる。`.claude/rules/beads.md` に「裏方」の記述がなければ、`APPLY.md` の前提条件で止まる。
- `.claude/rules/handoff.md` を v1 のまま改変していなければ、そのまま置き換わる。改変している場合は差分が示されるので、取り込み方を決める。
