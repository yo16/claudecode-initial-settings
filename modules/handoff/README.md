# handoff

Claude Code が停止するたびに git と beads の状態を揃え、翌日など、まっさらなコンテキストから作業を再開できるようにするためのルール。

## 版

| 版 | 要約 |
|---|---|
| v1 | 停止前に行う同期の手順（Issue の更新、コミット、最後の報告）と、再開時の手順を `.claude/rules/handoff.md` に置く。`git-autonomous@v1` と `beads@v1` に依存する |
| v2.0 | 最後のメッセージから Issue の ID を外し、作業の成果とユーザーに求めることだけを書くようにした。`beads@v2.0` 以降に依存する |
| v2.1 | 最後のメッセージで、ユーザーにしてほしいことがなければ「確認や操作は不要」と明記し、任意の作業は任意だと書くようにした。何をすべきか読み取れないメッセージで終えない |
| v3.0 | 「停止点ではないところで止まらない」を加えた。依頼の目的に至る残りの手順が明らかで判断を要しないなら、「次に〜ができます」と書いて止まらず続ける。確認してから進めるのは、選択肢で成果物が大きく変わるとき、元に戻せない操作や目的の外の変更、情報不足のときだけ |
