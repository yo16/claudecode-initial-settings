# handoff v3.0 の変更点

v2.1 からの差分と、上げるときの注意。

## 変更点

- 「停止点」に「停止点ではないところで止まらない」を加えた。「タスクが完了した」とは依頼の目的が達成されたときを指し、目的に至る残りの手順が明らかで判断を要しないなら、「次に〜ができます」「進めてよければ〜します」と書いて止まらず続けて進める。確認してから進めるのは、選択肢で成果物が大きく変わるとき、元に戻せない操作や依頼の目的の外にある変更、情報不足で推測が無駄になるときだけにした。依頼の範囲内の作業を次の候補として提示して止まり、ユーザーが毎回「進めて」と書く必要があったため。
- 「最後のメッセージに状況を書く」に、次にできることとして挙げるのは依頼の目的の外にある任意の作業だけにする、と加えた。

## v2.1 から上げるときの注意

- 前提条件は v2.1 と同じ。
- `.claude/rules/handoff.md` を v1、v2.0、v2.1 のまま改変していなければ、そのまま置き換わる。改変している場合は差分が示されるので、取り込み方を決める。
