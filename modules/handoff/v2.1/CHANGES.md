# handoff v2.1 の変更点

v2.0 からの差分と、上げるときの注意。

## 変更点

- 停止前の「最後のメッセージに状況を書く」に、ユーザーにしてほしいことがなければ「確認や操作は不要」と明記すること、任意の作業を勧めるときは任意であることとやらなくても何も起きないことを書くこと、何をすべきか読み取れないメッセージで終えないことを加えた。成果だけを並べて任意の確認作業を添えた報告が、ユーザーに「何をすべきかわからない」と受け取られたため。

## v2.0 から上げるときの注意

- 前提条件は v2.0 と同じ。
- `.claude/rules/handoff.md` を v1 または v2.0 のまま改変していなければ、そのまま置き換わる。改変している場合は差分が示されるので、取り込み方を決める。
