# service-readme

サービスの基本情報（サービス名、段階、GitHub リポジトリ、URL、インフラ、説明、公開日、UptimeRobot monitor ID）を、`README.md` の「サービス情報」節に書いて最新に保つためのルール。

## 版

| 版 | 要約 |
|---|---|
| v1 | 8 項目の表を `README.md` の「サービス情報」節に書き、段階の変化や URL の決定などのたびに更新するルールを `.claude/rules/service-readme.md` に置く。適用時に、リポジトリから読み取れる項目を埋め、残りはユーザーに確認して節を作る |
