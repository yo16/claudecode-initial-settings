# service-readme v1

> この文書は Claude Code が読んで実行する導入手順書です。
> 現在のリポジトリに対して、以下の手順を上から順に実行してください。
> 既存のファイルや設定と衝突する場合は、上書きせずユーザーに確認してください。

## 概要

このプロジェクトが提供するサービスの基本情報（サービス名、段階、GitHub リポジトリ、URL、インフラ、説明、公開日、UptimeRobot monitor ID）を、ルートの `README.md` の「サービス情報」節に表で書き、変わるたびに更新するルールを `.claude/rules/service-readme.md` に置きます。適用時に、リポジトリから読み取れる項目を埋め、残りはユーザーに確認して節を作ります。

## 前提条件

- 依存する他モジュール: なし
- `infra-readme` を併用する場合は、先に適用してください。`README.md` に「インフラ」節があれば、その内容を「インフラ」の行に使います。

前提条件を満たさない場合は、手順に進まずユーザーに報告してください。

## 手順

### 1. ルールファイルを配置する

`files/service-readme.md` を、現在のリポジトリの `.claude/rules/service-readme.md` にコピーしてください。`.claude/rules/` ディレクトリがなければ作成してください。

`.claude/rules/service-readme.md` が既に存在する場合は上書きせず、既存の内容と `files/service-readme.md` の差分をユーザーに示して、どうするか確認してください。

### 2. リポジトリから読み取れる項目を集める

次の項目の候補を、現在のリポジトリから集めてください。

- **サービス名**: `README.md` のタイトル。なければリポジトリのディレクトリ名。
- **GitHub リポジトリ**: `git remote get-url origin` の結果を `https://github.com/<owner>/<repo>` の形に直したもの。リモートがなければ「未定」。
- **インフラ**: `README.md` に「インフラ」節（または同じ役割の節）があれば、その表のサービス名。なければ、手順 3 でユーザーに尋ねる項目に加える。
- **説明**: `README.md` の冒頭に説明文があれば、それを 1〜2 文にまとめたもの。なければ、手順 3 でユーザーに尋ねる項目に加える。

### 3. 残りの項目をユーザーに確認する

手順 2 で集めた候補を示して確認を求め、合わせて次の項目を 1 回のメッセージでユーザーに尋ねてください。回答が揃うまで手順 4 に進まないでください。

- **段階**: `企画`、`開発中`、`公開中`、`休止`、`終了` のいずれか
- **URL**: 利用者がアクセスする URL。決まっていなければ「未定」
- **公開日**: 初めて公開した日（`YYYY-MM-DD`）。公開前なら「未公開」
- **UptimeRobot monitor ID**: 監視しているモニターの ID。監視していなければ「なし」
- 手順 2 で読み取れなかった項目

ユーザーの指示にこれらの値が含まれていれば、その項目は尋ねずにそれを使ってください。

### 4. `README.md` に「サービス情報」節を作る

`README.md` の状態に応じて、次のいずれかを行ってください。

- **サービスの URL や公開状況などを一覧にした節がない場合**: ルールファイルの「置く場所」と「書く内容」に従って、「サービス情報」節を作ってください。既存の記述は残してください。`README.md` がなければ、サービス名を見出しにして作成してください。
- **そのような節（「基本情報」「About」など）が既にある場合**: その節を書き換えず、ルールファイルの形にした場合の差分をユーザーに示して、どうするか確認してください。

## 完了条件

適用後、次をすべて確認し、結果をユーザーに報告してください。

- [ ] `.claude/rules/service-readme.md` が存在し、内容が `files/service-readme.md` と一致している
- [ ] `README.md` の「サービス情報」節（または同じ役割の既存の節）に、8 項目がすべて載っていて、空欄がない
- [ ] `README.md` に「インフラ」節があれば、「サービス情報」節の「インフラ」の行に、その節の表のサービスがすべて載っている
- [ ] `README.md` に秘密の値（API キー、トークン、パスワード）が書かれていない
- [ ] ユーザーへの報告に、表に書いた 8 項目の値を含めている
