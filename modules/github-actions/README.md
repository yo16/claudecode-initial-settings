# github-actions

GitHub Actions の無料枠（実行時間と保存容量）を節約して使うためのルール。枠はアカウント全体で共有しており、1 つのリポジトリが使いすぎると、ほかのリポジトリが使える分が減るため。

## 版

| 版 | 要約 |
|---|---|
| v1 | ワークフローを作るときと変えるときの決まりを `.claude/rules/github-actions.md` に置く。手元で済む検査は Actions に載せない、きっかけを絞る、ジョブを細かく分けない、Linux を使う、`timeout-minutes` を付ける、artifact の保存期間を短くする、作ったあとに所要時間を確かめる。適用時に既存のワークフローを点検して報告する（書き換えない） |
